# Laboratorio PLC 4.0

Simulador web (HTML, CSS y JavaScript puros, sin dependencias) basado en las Clases 1 a 6 del curso de Controladores Lógicos Programables.

- **PLC y E/S**: catálogo (LOGO! 8, S7-1200 1215C, S7-1500 1513-1 PN, MicroLogix 1400, CompactLogix L32E), IP, máscara y gateway con validación, entradas y salidas digitales y analógicas.
- **Simbología ISA 5.1**: biblioteca de símbolos, letras de identificación y tipos de línea.
- **Proceso**: arme el proceso arrastrando símbolos y asigne cada uno a una dirección del PLC. Incluye un tanque con nivel simulado.
- **GRAFCET** y **Ladder**: editores con ejecución en línea (ciclo de 100 ms).
- **Exportar PDF**: abre el diálogo de impresión con el informe; elija "Guardar como PDF".

## Publicar en GitHub Pages
1. Suba `index.html`, `styles.css`, `app.js` y `README.md` a un repositorio.
2. En Settings > Pages elija la rama `main` y la carpeta `/ (root)`.

Los valores de E/S de cada PLC son capacidades típicas de referencia; verifique con la hoja de datos del fabricante.
